# Freedraw PDF 0.13.4

This release reduces repeated work in large annotated documents, improves finger input routing, and restores the visible eraser pointer.

## Changes

- Page navigation counts annotations in one pass instead of scanning the entire document for each page.
- Cached stroke redraws reuse geometry without rehashing every point or serializing stroke settings. Cached outlines can be released when their strokes are no longer referenced.
- Live drawing and export no longer build unused SVG strings after painting canvas strokes.
- Production JavaScript is minified, and annotation sidecars use compact JSON with the same editable data format.
- In **Pan with finger** mode, ordinary touch contacts cannot become ink merely because a device reports pressure, a small contact area, or tilt. Explicit pen and stylus signals still draw.
- In **Draw with finger** mode, the selection tool accepts finger input. Finger navigation works across annotation tools in **Pan with finger** mode.
- The eraser ring paints above the annotation layers and appears at the last pointer position when switching tools.
- Removed unused notebook, geometry, caret, device-detection, and styling code. Added checks for unused exports, runtime work, and the compiled plugin.

## Validation

The local 10,000-stroke, 100-page regression fixture reduces page enumeration from 1,000,000 annotation visits to 10,000. Warm outline lookups perform no settings serialization. These are focused measurements, not an end-to-end device latency claim.

Automated checks cover drawing geometry, pressure, erasing, finger routing, selection, page handling, saving/recovery, generated PDF sizes, and loading the minified plugin. Physical Windows, Android, and Apple Pencil testing remains necessary; issue #2 is not yet confirmed resolved on the reporting devices.

## Install

Download `freedraw-pdf-0.13.4.zip` and extract `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/freedraw-pdf` in your vault. Reload Obsidian. Requires Obsidian 1.12.0 or later.

Existing PDFs and annotation sidecars remain compatible. Local development snapshots are excluded from the repository and release assets.
