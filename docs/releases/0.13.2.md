# Freedraw PDF 0.13.2 — v2

This release separates the original implementation into **v0**, preserves **v1 / 0.12.10**, and makes **v2 / 0.13.2** the maintained plugin.

## Fixes and improvements

- **Ink:** adjustable stabilization; consistent live and committed geometry in Balanced/Accurate mode; stable pen-up pressure; stroke settings stored per stroke so later settings changes do not alter existing ink, including after reopen, zoom or export.
- **Erasing:** smooth rounded heads and tails on surviving segments, with taper suppressed at cut ends.
- **Responsiveness:** reuse unchanged page frames, avoid synchronous pixel readback during publication, cache stationary ink during selection dragging, and let the native text editor render typing and caret movement.
- **Tools:** annotation-mode shortcuts 1–5, with typing/composition/modifier guards. Horizontal inline/floating toolbar; vertical toolbar removed.
- **Pages:** temporary pages appear at their PDF anchor, and quick-add retains the page where its menu was opened. New PDF source pages are white; colour and template are editable sidecar overlays through Page → Paper / Template.
- **Saving:** queued writes drain edits received during a save; file switches flush the prior document; conflicting views are detected; failed saves attempt a separate recovery sidecar. Invalid sidecars block editing, and original sidecars survive PDF rename/deletion.
- **Privacy:** sidecar images cannot load network URLs. Test deployment copies only the three plugin files and preserves malformed plugin-list configuration; automatic whole-vault OneDrive copying is removed. Packaging leaves test vaults alone.

## Installation and compatibility

Use the attached ZIP, or install `main.js`, `manifest.json`, and `styles.css` in `.obsidian/plugins/freedraw-pdf`. Requires Obsidian 1.12.0+. V0, v1 and v2 use the same plugin ID; install one build per vault. Older strokes receive a stable baseline from settings at upgrade; appearance changes made by earlier builds cannot be reconstructed.

## Validation and limits

The release is checked with the v2 regression suite, TypeScript/module checks, production build, package inspection, repository privacy checks, and dependency audit. See [the safety review](https://github.com/vividasasana/freedraw-pdf/blob/0.13.2/docs/security-review-0.13.2.md) for evidence and scope.

Physical stylus latency, palm rejection, pinch zoom and long-PDF behavior still need testing in Obsidian; issue #2 is not marked fixed. Smooth preview can differ at pen-up. Exports remain flattened raster PDFs. Conflicts require manual reconciliation; recovery cannot succeed on unwritable storage or guarantee coordination with external sync tools.
