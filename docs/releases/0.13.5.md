# Freedraw PDF 0.13.5

- Return to the v2 drawing implementation following reports of slower handwriting in the withdrawn 0.13.4 build.
- Tighten finger-pan input classification: touch pressure, contact size and angle alone no longer admit a finger as pen input. Explicit pen and stylus input remain supported, as does intentional finger drawing.
- Address community-review type safety, detached canvas creation and color-grid styling warnings.
- Minify the production JavaScript bundle and attach only the three supported plugin assets to releases.

Issue #2 remains under device validation. Automated tests cover simulated finger-pan, pen/Pencil and finger-drawing input, but do not establish that every affected device is fixed.
