# Privacy

Freedraw PDF stores editable annotations beside your PDF in a companion `.annot.json` file. Imported annotation images are stored with the annotation data. Keep both files when backing up or transferring your work.

The current published plugin does not use analytics or an online recognition service. Drawing, viewing and exporting annotations do not require an account. Your vault's storage, backup and sync settings determine where files are copied.

## Sharing files

Annotation files, recovery copies and local checkpoints may contain earlier content. Removing a visible annotation is not secure erasure. Review these files before sharing a vault or document.

Exports preserve the original PDF content and add annotations. Exporting is not a redaction or anonymisation tool; check the exported copy before sharing it.

## Clipboard and images

Clipboard access is used by copy/paste and diagnostic commands. Diagnostics are not uploaded automatically; review them before sharing.

Annotation image loaders accept embedded image data and reject remote image URLs and local file URLs.

## Security reports

Follow the [security policy](../SECURITY.md) to report a security concern. Do not include credentials, private documents or personal data in a public issue.
