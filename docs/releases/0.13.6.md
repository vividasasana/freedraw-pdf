# Freedraw PDF 0.13.6

## SVG stroke display

**This version uses SVG paths to display strokes.** Existing vector strokes follow the page size during zoom without rebuilding unchanged geometry. The continuous ink engine and save-conflict fixes are included in this build.

iPad users have reported lag, crashes, disappearing PDF pages, and zoom-alignment failures. Hardware confirmation is still required; automated checks do not establish device stability. This is an unpublished release candidate with Smoothest/Linear/debugging-off defaults and customizable Quick add pages.

## Local candidate updates — 10 October 2026

- Choose cleanup scope with an editable folder/PDF path input and optional native autocomplete suggestions. Paths can be typed directly without selecting a suggestion; validation runs on Continue and accepts case-insensitive matches. One-PDF, folder-and-subfolders, and whole-vault scopes remain available.
- Align and regroup settings, keep stroke-end controls visible, and make saving messages optional under Debug → Action notices. Save failures remain visible.
- Allow finger panning with Text, Select, and Region in Pan with finger mode. Preserve the text-box selection across Text/Select switches and editor blur, and reopen the selected box directly for typing.
- Confirm deletion of annotation data with the PDF's deletion and last-modified times. Move/relink sidecars when PDFs are renamed; offer recovery files related to the current PDF in the same folder.
- Combine recovered JSONs for the same PDF. Deduplicate identical strokes across different IDs and preserve different saved stroke versions as separate stacked strokes. Recognize OneDrive conflict-copy filenames. Save the combined main JSON before removing consumed copies.
- Default deleted-PDF cleanup to the whole vault, with optional folder/PDF limits. Files are moved to recoverable trash after confirmation.
- Verify the main JSON after writing, retain per-device checkpoints, and offer recovery when sync leaves annotation JSON missing or older. These protections do not confirm cloud upload or guarantee OneDrive delivery.

The separate Annotation Sync Guard companion is not part of the Freedraw PDF release ZIP. No release is published by this preparation step.

## Changes

- Add **Pages / Quick add** settings for **Quick add after current**: inherit the previous temporary page's template and colour within the same PDF, or always use configured defaults. Select Blank, Ruled, Grid, or Dotted and a default paper colour. With no previous temporary page, configured defaults apply. This implements the options described in issue #3.
- Organize settings under clear section headings and separate cards. Template/colour defaults appear only with Configured defaults selected. Remove redundant Page-menu navigation and working-PDF conversion shortcuts, and support custom colours in page creation and editable-page colour menus.
- Default stroke preview is **Smoothest**, pressure curve is **Linear**, and debugging displays are **off**.
- Display handwriting and annotations as crisp SVG paths, including at high zoom.
- Scale retained SVG frames immediately with the page during zoom. Unchanged vector pages reuse their existing paths instead of rebuilding all stroke geometry after each zoom.
- Improve Pencil sample ordering, retain the initial contact point and final curves, and prevent missing-pressure or lift events from unexpectedly widening short strokes.
- Use actual pressure for Apple Pencil and other stylus input in every pressure mode. Speed-based pressure remains available for mouse and finger input.
- Add Fast, Accurate, and Smoothest stroke previews. Smoothest uses the automatic smoothing mode.
- Round connected stroke joins and offer Original / Extra smooth width smoothing. Extra smooth follows pressure locally without widening earlier light sections toward later pressure peaks.
- Join changing-width round sections with tangent edges and retain finer curve detail at sparse bends, reducing hard edges without adding pressure from writing speed.
- Add continuous cubic fitting and monotone pressure-width interpolation for new ink, with bounded spatial correction, preserved pressure peaks, measured endpoints, and matching live/saved geometry. Use compact tangent tubes and correct SVG long-arc direction.
- Compare sidecar annotation content rather than JSON formatting or save timestamps. Independent new-stroke additions from another view/device merge; genuine edits or deletions remain conflict-protected and local recovery copies are retained.
- Restrict new-stroke pressure sensitivity to 0–1. Existing saved strokes retain their stored rendering settings.
- Reduce annotation-loading work and bound temporary canvas and eraser buffers; release rendering resources for pages outside the viewport.

Automated checks cover input replays, geometry, persistence, rendering, exports, startup, and deployment privacy. They do not establish device-level latency or guarantee that all iPad zoom crashes are resolved. Issue #2 remains open for affected-device confirmation.
